# Referências e licenças da interface

A identidade de cores e o conceito de ingresso/livro seguem a referência EventBook fornecida pelo usuário. O símbolo vetorial é uma interpretação para a interface; o arquivo de fonte original não foi fornecido. Manrope Variable é distribuída localmente pelo pacote @fontsource-variable/manrope, sob OFL-1.1.

`BlurFade.tsx` é uma adaptação simplificada do Blur Fade de Magic UI, encontrado no 21st.dev, ajustado para o padrão de exports do projeto e preferência de movimento reduzido.

- Catálogo: https://21st.dev/@dillionverma/components/blur-fade
- Origem: https://github.com/magicuidesign/magicui/blob/main/apps/www/registry/magicui/blur-fade.tsx
- Fotografia decorativa de música ao vivo: https://unsplash.com/photos/1470229722913-7c0e2dbbafd3 (arquivo servido por images.unsplash.com/photo-1470229722913-7c0e2dbbafd3). Não representa um evento específico do catálogo.
- Ícones: Lucide React (ISC). Animações: Motion (MIT).
